# ADET M2A1: Student Grades

This is a public starter template for an ADET Dart activity. Students create private copies in HAU-6ADET. The public starter intentionally contains a blank program and blank identity fields. Never insert real student details, private course data or credentials into this repository. Keep this guide accurate when the activity changes.

Follow [AI-DEVELOPMENT](https://tjakoen.github.io/standards/ai-development), [SESSION-LOOP](https://tjakoen.github.io/standards/session-loop), and [LOOP](https://tjakoen.github.io/standards/loop). Use [VOICE](https://tjakoen.github.io/standards/voice) and [README-STANDARD](https://tjakoen.github.io/standards/readme-standard) for prose.

Verify with dart pub get, dart analyze, dart test and git diff --check. The untouched starter is expected to fail readiness checks. Prove a completed synthetic student copy passes, a wrong greeting fails, and blank identity details fail before publishing a template change. Obtain an independent second pass. Keep validation fixtures and solution copies outside this public repository.

Code lives in bin/, student-facing checks in test/, and first-use instructions in README.md. student.json is the course engine's identity input and belongs at the root. AGENTS.md is a symlink to this file. Grading and Canvas operations belong in the private teacher repositories. Student-owned CI is feedback, not authoritative grading evidence. Commit and push only within the authorized task; use gitmoji subjects and no AI coauthor trailers.
