# Sources and assistance

Complete this file for every activity and commit it with your work. Credit the sources and help you used, including when you completed the activity without AI.

## Sources

List the websites, documentation, tutorials, code examples or other references you used. For each source, give its title, a link or citation, and a short note about what you learned or adapted. If you used no external sources, write **No external sources used**.

## Assistance

Describe any help you received from another person or a tool and how it helped. If you used AI, name the tool and explain what you asked it to do, what you kept or changed, and how you checked the result. If you used no AI, write **No AI assistance used**.
